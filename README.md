# Kenzitui: Ncurses Task Manager (C Learning Project)

Kenzitui is a terminal-based project and task management tool built with C and ncurses.

## 📂 Folder Structure

- `src/`: Source files (.c)
- `include/`: Header files (.h)
- `bin/`: Compiled executables
- `obj/`: Object files (.o)
- `tests/`: Test files
- `docs/`: Documentation
- `Makefile`: Build system configuration
- `CONTEXT.md`: Project roadmap and learning goals

## 🛠 Tech Stack

- **Language**: C (C11 standard)
- **UI Library**: `ncurses`
- **Build System**: `Makefile`

## 🚀 Getting Started

1.  **Dependencies**: Install `libncurses-dev` (on Ubuntu/Debian).
2.  **Build Main App**: Run `make` to compile.
3.  **Run Main App**: Execute `./bin/kenzitui`.
4.  **Run Tests**: Run `make test` to compile and execute the task logic tests.
5.  **Clean**: Run `make clean` to remove build artifacts.
